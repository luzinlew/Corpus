- причины: (1) `terminate()` убивает npx, а не дочерний deno; (2) `wait_port` до `try:` — при неподнявшемся сервере finally не выполняется; (3) занятый порт молча используется старым сервером
- план: проверка занятых портов до старта; каждый сервер в своей группе процессов (`start_new_session=True`); запуск и ожидание портов внутри `try`; после старта — все процессы живы; в finally — SIGTERM группам, через 10 с SIGKILL, проверка, что порты закрылись (иначе FAIL и exit 1); SIGTERM самого теста → SystemExit, чтобы finally выполнился
- проверка: обычный прогон (ALL PASSED, 126 PASS, после — нет процессов, порты закрыты); занятый порт 8000 → быстрый FAIL без запуска серверов; прерывание SIGTERM/SIGINT посреди прогона → нет процессов; push_test; build --check
- ревью: только qa-quick (security/qa-review не нужны: тестовая обвязка, не код приложения)
- попытка 1 (implementer): QA FAIL D-TERM — после SIGTERM тест висел >19 мин, серверы живы. Причина (разбор координатора): `sys.exit` в обработчике SIGTERM → asyncio.run отменяет все задачи, включая читателя Playwright → main() не доходит до finally
- попытка 2 (implementer): SIGTERM через `loop.add_signal_handler` отменяет только main(); `CancelledError` → exit 143
- проверки (qa-quick, scratchpad/t001-qa.sh): A до — нет процессов, порты закрыты; B обычный прогон exit=0, 126 PASS, ALL PASSED, после — нет процессов, порты закрыты; C порт 8000 занят → exit=1 за <1 с, `FAIL test ports already in use: 8000`, серверы не запускались; D-TERM exit=143, D-INT exit=130, после обоих — нет процессов, порты закрыты, без `Task was destroyed`; push_test ALL PUSH TESTS PASSED; build --check up to date; дерево — только tools/e2e_test.py; координатор перепроверил ps и порты отдельно
